# Programming Course

A self-authored, 56-lesson systems programming curriculum, built with a
"Machine-Up" philosophy: starting from raw x86 binary machine code and
building upward through x86 Assembly, C, and C++.

I teach this course independently (freelance), and wrote every lesson
and example from scratch. This repo holds a selection of the example
programs used throughout the course and will eventually hold the entire course.

## Curriculum progression

The course moves through four broad stages:

1. **Foundations** — digital logic, binary, the command line, and x86
   architecture
2. **Assembly fundamentals** - memory segments (code/data/BSS/stack),
   comparisons and jumps, functions, and calling conventions
3. **C programming** - from the C runtime up through pointers, arrays,
   structs, file I/O, and the C preprocessor
4. **C++ and OOP** - classes, inheritance, polymorphism, templates,
   exceptions, and multi-threading

The course is cross-platform throughout, covering Windows (WSL), Linux,
and macOS — including Objective-C instruction for Mac-specific topics.
